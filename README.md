# gestured

A daemon for mapping hand gestures to system commands / macros.

Web UI is hosted over 127.0.0.1:2026, and currently just streams the mjpeg output of the camera.

To build:
```
cmake --build build-release
```
Then, to run:
```
./build-release/gestured
```
systmd daemon is coming soon.
